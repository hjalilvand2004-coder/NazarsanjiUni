## 🔒 امنیت

- **هش رمز عبور:** PBKDF2-HMAC-SHA256 با ۱۰۰,۰۰۰ iteration + salt
- **Session:** با SECRET_KEY + TTL ۸ ساعته برای ادمین، ۲۴ ساعته برای دانشجو
- **Audit Log:** تمام عملیات ادمین ثبت می‌شود
- **کنترل دسترسی:** در سطح سرور کنترل می‌شود
- **جلوگیری از ثبت مجدد** پیشنهاد پس از مهلت
- **Path traversal protection** در دانلود APK
