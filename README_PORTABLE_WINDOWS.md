# نسخهٔ پرتیبل ویندوز (Windows Portable) — BaleSurvey

نسخهٔ پرتیبل ویندوزِ سامانهٔ نظرسنجی دروس، یک پوشهٔ مستقل است که **بدون نصب Python** روی هر ویندوزی اجرا می‌شود. کافی است پوشه را روی فلش یا هر مسیر کپی و `run_portable.bat` را اجرا کنید.

## نحوهٔ استفاده برای کاربر نهایی

1. فایل `BaleSurvey-portable-windows.zip` را از حالت فشرده خارج کنید (مثلاً در `D:\BaleSurvey\`).
2. روی **`run_portable.bat`** دو بار کلیک کنید.
3. پس از چند ثانیه مرورگر به‌صورت خودکار در آدرس **http://127.0.0.1:8082** باز می‌شود.
4. ورود ادمین: `admin` / `admin@1405`
5. برای توقف: در پنجرهٔ کنسول `Ctrl+C` بزنید یا `stop_portable.bat` را اجرا کنید.

> اولین اجرا چند ثانیه طول می‌کشد؛ دیتابیس و جدول‌ها ساخته و از فایل‌های اکسل پایه تغذیه می‌شوند.

### داده‌ها کجا ذخیره می‌شوند؟
همهٔ داده‌های نوشتنی (دیتابیس SQLite، تنظیمات، پروفایل اساتید، بکاپ‌ها) در پوشهٔ **`data/`** کنار فایل اجرایی ذخیره می‌شوند. برای پشتیبان‌گیری یا انتقال به دستگاه دیگر، فقط همین پوشه را کپی کنید.

### پورت اشغال است؟
اگر پورت 8082 درگیر باشد، متغیر محیطی `BALE_PORT` را پیش از اجرا تغییر دهید:
```bat
set BALE_PORT=8090
run_portable.bat
```

## ساخت نسخهٔ پرتیبل (برای توسعه‌دهنده)

### روش ۱ — خودکار با GitHub Actions (پیشنهادی)
هر بار که یک تگ `v*` بزنید، CI روی `windows-latest` بسته را می‌سازد و به‌صورت Release منتشر می‌کند:
```bat
git tag v3.19.4
git push origin v3.19.4
```
می‌توانید از تب **Actions → Build Windows Portable → Run workflow** هم به‌صورت دستی اجرا کنید. خروجی (ZIP) در Artifacts و در صفحهٔ Releases قرار می‌گیرد.

### روش ۲ — دستی روی ویندوز
پیش‌نیاز: Python 3.10+ روی ویندوز.
```bat
build_windows.bat
```
این اسکریپت وابستگی‌ها و PyInstaller را نصب و بستهٔ پرتیبل را در `dist\BaleSurvey\` می‌سازد. سپس `run_portable.bat` را از همان پوشه اجرا کنید.

## ساختار بستهٔ پرتیبل
```
BaleSurvey/
├─ BaleSurvey.exe              ← فایل اجرایی (لانچر کنسولی)
├─ run_portable.bat             ← اجرای سرور + باز کردن مرورگر
├─ stop_portable.bat            ← توقف سرور
├─ README_PORTABLE_WINDOWS.md
├─ data/                        ← نوشتنی (ساخته‌شده در اولین اجرا)
│  ├─ courses_survey.db         ← دیتابیس SQLite
│  ├─ app_settings.json         ← تنظیمات SSO
│  ├─ instructor_profiles.json
│  ├─ instructors_sync.json
│  ├─ sso_links.json
│  ├─ downloads/                ← خروجی‌های APK
│  └─ response_reset_backups/   ← بکاپ‌های ریست
└─ _internal/                   ← فقط‌خواندنی (منابع + کتابخانه‌ها)
   ├─ templates/                ← قالب‌های Jinja2
   ├─ static/                   ← CSS/JS/تصاویر
   ├─ data/
   │  ├─ CourceListYekta.xlsx   ← فهرست دروس یکتا (برای seed)
   │  └─ CourceListDetail.xlsx  ← فهرست دروس تفکیکی (برای seed)
   └─ ... (Python runtime + وابستگی‌ها)
```

## نحوهٔ کار مسیرها (لایهٔ `portable.py`)
- **منابع فقط‌خواندنی** (templates/static/xlsx پایه): از `sys._MEIPASS` (درون `_internal/`) خوانده می‌شوند.
- **فایل‌های نوشتنی** (db/json/backup): در `<exe_dir>/data/` قرار می‌گیرند (کنار `.exe`)، نه داخل بسته.
- در حالت **dev** (اجرای سورس)، همهٔ مسیرها دقیقاً مثل نسخهٔ قبلی می‌مانند (پروژه‌ریت/`data/`) — بدون نیاز به مهاجرت داده.

## ملاحظات
- اتصال پیش‌فرض به `127.0.0.1` (فقط همین ماشین) محدود است تا روی شبکه اشتراک‌گذاری نشود. برای دسترسی LAN، `set BALE_HOST=0.0.0.0` کنید.
- اندازهٔ بسته به‌دلیل pandas/cryptography حدود ۸۰–۱۲۰ مگابایت است.
- بله‌بات/مینی‌اپ/SSO به سرور خارجی وصل می‌شوند؛ در محیط ایزوله فقط بخش وب و ادمین کار می‌کند.
